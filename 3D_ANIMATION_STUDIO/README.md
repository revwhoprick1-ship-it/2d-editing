# 3D Animation Studio: YouTube Shorts pipeline

A reusable, scripted, **100% free / open‑source** production system for vertical 3D animated Shorts starring one permanent mascot. Everything (character, environments, animation, narration, music, SFX, mix, captions, export, QA) is generated by code in this folder, so every video is reproducible.

## Folder map
```
REFERENCE/        REFERENCE_ANALYSIS.md, STYLE_BIBLE.md, reference_frames/ (evidence)
CHARACTER/        mascot.blend, mascot_rig.blend, expressions/, animations/, reference_sheets/
ASSETS/           fonts/ (Montserrat OFL) + procedural asset code lives in PIPELINE
AUDIO/            narrator/ (voice choice + auditions), music/ (licence register),
                  sound_effects/ (46 original SFX + LIBRARY.json), ambience/
PIPELINE/
  blender_scripts/  studio_lib/ (mascot_build, mascot_rig, mascot_api, bio_assets, materials,
                    render_setup, scene_kit, geo), build_mascot.py, render_character_sheets.py,
                    anim_test.py, videos/<videoXXX>.py (one module per video)
  tts/              narrate.py, voice_qc.py, qc_narration.py, audition.py   (Kokoro‑82M, local)
  audio/            dsp.py, sfx_synth.py, music_gen.py, mix.py, cue_sheet_md.py
  rendering/        render_shot.py, render_video.sh
  editing/          assemble.py (frames + captions + audio → MP4)
  quality_control/  qc_video.py
TEMPLATES/        production_template.md, storyboard_template.md, audio_cue_template.md
VIDEOS/VIDEO_001/ research, concepts, drafts, reviews, script, storyboard, cue sheet, audio, blender/, QA
EXPORTS/          final MP4s
DOCUMENTATION/    HARDWARE_AND_RENDERING.md, RIG_GUIDE.md, PIPELINE_GUIDE.md
```

## Quick start
```bash
# 1. character (only after changing mascot_config.py)
blender -b --factory-startup --python PIPELINE/blender_scripts/build_mascot.py
blender -b CHARACTER/mascot_rig.blend --python PIPELINE/blender_scripts/render_character_sheets.py

# 2. narration + QC
PY=/opt/tools/tts312/bin/python
$PY PIPELINE/tts/narrate.py VIDEOS/VIDEO_001/script.json VIDEOS/VIDEO_001/audio/narration
$PY PIPELINE/tts/qc_narration.py VIDEOS/VIDEO_001/audio/narration

# 3. music, SFX, mix
$PY PIPELINE/audio/music_gen.py video001 VIDEOS/VIDEO_001/audio/music_score.wav
$PY PIPELINE/audio/mix.py VIDEOS/VIDEO_001/audio/cues.json

# 4. preview animatic, then final frames (2 workers on a 4-core CPU)
PIPELINE/rendering/render_video.sh video001 270x480 2 3 VIDEOS/VIDEO_001/preview/frames
PIPELINE/rendering/render_video.sh video001 540x960 6 1 VIDEOS/VIDEO_001/frames

# 5. edit + export + QA
python3 PIPELINE/editing/assemble.py VIDEOS/VIDEO_001 --frames-root VIDEOS/VIDEO_001/frames --out EXPORTS/VIDEO_001.mp4
python3 PIPELINE/quality_control/qc_video.py EXPORTS/VIDEO_001.mp4 --video-dir VIDEOS/VIDEO_001 --out VIDEOS/VIDEO_001/qc
```
See `DOCUMENTATION/PIPELINE_GUIDE.md` to make VIDEO_002.

## Status and honest limitations
* **Reference videos:** only metadata, transcripts, thumbnails and Ref 1's storyboard frames could be fetched (the video streams were blocked by YouTube). Please supply the MP4s for a full frame‑by‑frame and audio analysis.
* **Mascot image:** the uploaded image did not reach this environment. The mascot was built from the written description. Send the image to recalibrate `PIPELINE/blender_scripts/studio_lib/mascot_config.py`.
* **Hardware:** a CPU‑only VM with no GPU. Finals render at 540×960 and are upscaled to 1080×1920. Native 1080 is a single flag on GPU hardware.
* Narration naturalness was checked with ASR and acoustic proxies. **A human listening pass is still recommended.**
