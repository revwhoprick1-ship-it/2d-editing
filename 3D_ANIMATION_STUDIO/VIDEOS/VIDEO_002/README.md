## Rebuild from scratch
```bash
# characters (mascot + 3 extras)
blender -b --factory-startup --python PIPELINE/blender_scripts/build_mascot.py
for n in GRANDMA BUSINESSMAN KID; do blender -b --factory-startup --python PIPELINE/blender_scripts/build_extras.py -- $n; done
# narration (Kokoro, af_heart) + QC
/opt/tools/tts312/bin/python PIPELINE/tts/narrate.py VIDEOS/VIDEO_002/script.json VIDEOS/VIDEO_002/audio/narration
# sound: SFX pack, score, cues, mix
/opt/tools/tts312/bin/python PIPELINE/audio/sfx_comedy.py AUDIO
/opt/tools/tts312/bin/python PIPELINE/audio/music_gen.py video002 VIDEOS/VIDEO_002/audio/music_score.wav
/opt/tools/tts312/bin/python VIDEOS/VIDEO_002/audio/build_cues.py
/opt/tools/tts312/bin/python PIPELINE/audio/mix.py VIDEOS/VIDEO_002/audio/cues.json
# overlay anchors, then render only the frames the edit uses
blender -b --factory-startup --python PIPELINE/rendering/annotate_v2.py -- video002 EL_CCTV EL_BLAME1 EL_BLAME3 EL_BLAME4 EL_WHISTLE
python3 PIPELINE/rendering/render_needed.py VIDEOS/VIDEO_002/edit_video002.py video002 \
    --out VIDEOS/VIDEO_002/frames --res 540x960 --samples 3 --eevee use_raytracing=0 --lanes 2
# edit + export, then QA
python3 PIPELINE/editing/edl_engine.py VIDEOS/VIDEO_002/edit_video002.py --frames VIDEOS/VIDEO_002/frames \
    --out EXPORTS/VIDEO_002_everyone_farted.mp4 --audio VIDEOS/VIDEO_002/audio/mix_master.wav --crf 18
python3 PIPELINE/quality_control/qc_video.py EXPORTS/VIDEO_002_everyone_farted.mp4 --out VIDEOS/VIDEO_002/qc
python3 PIPELINE/quality_control/loop_test.py EXPORTS/VIDEO_002_everyone_farted.mp4 --out VIDEOS/VIDEO_002/qc
```

## Code for this video
* 3D: `PIPELINE/blender_scripts/videos/video002.py` (sets, cast, performance, cameras, the render job list)
* Sets: `PIPELINE/blender_scripts/studio_lib/sets_v2.py` (elevator, news studio, wedding, globe, gas puffs)
* Cast: `studio_lib/extras_build.py` (grandma, businessman, kid, all built from the mascot generator)
* Edit: `edit_video002.py` (the EDL) + `PIPELINE/editing/edl_engine.py`
* Sound: `PIPELINE/audio/sfx_comedy.py`, `music_gen.py` (`cue_video002`), `audio/build_cues.py`, `mix.py`

All visuals, music and sound effects are generated by the studio's own code. Fonts are OFL
(Montserrat, Noto Emoji). The Earth texture comes from the public‑domain `global-land-mask` data.
